# AJ's Music & SFX Tools

A calm, accessible browser keyboard: play with your computer keyboard, mouse or touch, pick from
eight instruments or your own sounds, rebind any key, then record, loop, edit and export
(WAV, MP3/OGG, MIDI).

Early days: see [docs/3-state/ProjectState.md](docs/3-state/ProjectState.md) for progress and
[docs/1-landing/README.md](docs/1-landing/README.md) for everything else.
