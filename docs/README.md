# Docs

AJ's Music & SFX Tools is a calm, accessible browser keyboard for playing, recording and exporting
music and sound effects. This folder explains it.

- `1-landing/`: start here, the full index
- `2-roadmap/`: what "finished" means
- `3-state/`: how far along it is
- `4-systems/`: how the main parts work
- `5-today/`: what's being worked on now
- `6-decisions/`: why things were decided
- `plans/`, `archive/`, `generated/`: work plans, old docs, tool-made reports

Full index: [1-landing/README.md](1-landing/README.md).
